Free Online osu!mania Editor & Map Viewer

Cascade is a browser-based osu!mania beatmap editor and VSRG map viewer. Import .osz / .osu files, chart notes on a vertical scrolling playfield, set timing, hear real osu! hitsounds, collaborate in realtime, and export a ready-to-play map. No download, no install.

What you can do

  • Edit osu!mania beatmaps online (1K to 18K), with rice notes and long notes
  • Preview and view osu!mania maps right in the browser
  • Import .osz / .osu, export .osu or .osz
  • Set BPM and timing with tap tempo and a metronome
  • Real osu! hitsounds and .osk skin support
  • Realtime collaborative mapping with live comments

osu!mania editor FAQ

Is Cascade free to use?
Yes. Cascade is a free online osu!mania editor that runs entirely in your web browser.
Do I need to install anything?
No. It is a web app: open it in any modern browser and start mapping immediately.
Can I import my existing osu!mania beatmaps?
Yes. Drag an .osz or .osu file onto the page to edit an existing map, then export it back out.
Is this a VSRG editor?
Yes. Cascade charts on a standard vertical-scrolling rhythm-game (VSRG) playfield and exports osu!mania .osu / .osz files.
