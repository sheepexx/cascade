Before you install

Windows SmartScreen

The builds are not code-signed yet, so SmartScreen shows “Windows protected your PC”. Choose More info, then Run anyway.

WebView2

The installers fetch Microsoft’s WebView2 runtime when it is missing. Windows 11 already has it, and the portable exe needs it too.

macOS Gatekeeper

The macOS build is not signed by Apple yet, so the first launch is blocked. Right-click Cascade in Applications and choose Open, or allow it under System Settings, Privacy and Security.

Running the AppImage

Mark it executable with chmod +x before the first run. The deb and rpm packages install the usual way.

osu! integration

Reading the map currently open in osu! works on Windows only. Everything else in the editor behaves the same on all three systems.

Updating

Cascade checks for updates when it starts and installs them in one click, with a quick restart. You only need this page for the first install.
