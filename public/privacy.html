Cascade

Privacy Policy

Last updated: 8 September 2026

Cascade is an osu!mania beatmap editor at cascade.sheepex.net, available in the browser and as a Windows app. Both run the same editor and this policy covers both. You can use the whole editor without an account; everything you make stays on your device unless you log in. Account settings sync automatically after login, while projects and skins are uploaded only when you choose their cloud actions. This page explains what is stored where, and how to get it removed.

Using the editor without an account

  • Projects, autosaves, imported audio/skins and your editor settings are stored locally on your device (localStorage / IndexedDB, kept in the app's own data folder in the Windows app). They never leave your device and we cannot see them. Clearing this site's data, or uninstalling the app, removes them.
  • We record a small usage event when the editor is opened, when a project is created and when a feature such as an export or an import is used. Each event holds the event type, the browser or embedded webview name and version, your operating system name, whether it came from the website or the Windows app, and the Cascade version you are running. No IP address and no map content is included in these events. If you are logged in, the event is linked to your account so we can see which build you are on and support you; if you are not, it is stored with no account attached.
  • We use no advertising and no third-party tracking scripts.

The Windows app

The desktop app is the same editor in a native window. It uses the same account, the same cloud features and the same usage events described above, with two differences you should know about:

  • Its usage events are marked as coming from the app rather than the website, and carry the app version, so we can see which builds are still in use and stop supporting old ones sensibly.
  • Downloading an installer is counted. We store the version, which installer it was (setup, MSI or portable) and the operating system name from the request, and nothing else. No IP address, no account and no device identifier is kept with it, so a download cannot be traced back to a person. The installers themselves are served from Cloudflare R2.

The app has no auto-updater, no crash reporting and no background reporting. It never sends us your file paths, your installed programs or anything else about your PC, and it only talks to our services when you use a feature that needs them.

If you log in with osu!

Login uses osu!'s official OAuth flow, so we never see your osu! password. After you approve, we store your public osu! profile basics in our database: your osu! user id, username and avatar URL. A session cookie keeps you signed in; it identifies your session and nothing else.

Cloud saves and community features

If you use these features while logged in, we store what you submit:

  • Cloud projects: your charts and their assets (audio, background images or video, skins), linked to your account, plus the accounts of collaborators you invite.
  • Account settings: editor, playtest, shortcut, display, language and audio preferences used to keep your devices in sync.
  • Account skins: up to two skin files that you explicitly upload. Other devices receive their names and file sizes; the files download only when you request them.
  • Comments you leave on shared projects.
  • Presets/patterns you publish for others.
  • Feedback you send through the feedback form.

Deleting a project, comment or preset in the app removes it from our database. Uploaded maps are private to you and your invited collaborators unless a sharing feature explicitly says otherwise.

Where the data lives

Cascade runs on three infrastructure providers, which process data on our behalf: Supabase (database), Cloudflare (login/session service, file storage and desktop installer hosting) and Vercel (site hosting). Like any web host, they may keep short-lived technical logs (including IP addresses) to run and secure their services.

Deleting your data

  • Projects, account skins, comments and presets: delete them directly in the app.
  • Your account and everything tied to it: email contact@sheepex.net from any address, naming your osu! username, and we will remove it.
  • Local data: clear this site's data in your browser, or uninstall the Windows app and delete its data folder.

Changes and contact

If this policy changes in a way that matters, the date above changes with it. Questions or requests: contact@sheepex.net.
